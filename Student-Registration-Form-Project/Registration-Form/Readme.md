# Student Registration Form

## Project Description

A responsive Student Registration Form developed using HTML, CSS and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Student name and email validation
- Phone number validation
- Gender selection
- Date of birth
- Course selection
- Password confirmation
- Responsive design
- Success message

## Project Structure

- index.html
- style.css
- script.js

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
